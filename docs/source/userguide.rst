
User Guide

This document explains how to use :term:`LCPOM` in a practical sense. To see the systems that :term:`LCPOM` is capable of simulating, you can run the example included :ref:`below <part:_quick_guide>`.

Installation
============
The use and installation of **LCPOM** is relatively easy, since it makes use of standard Python packages. 

Please make sure that the following are already installed in your environment:

.. dropdown:: System Requirements

    - ``numpy``
    - ``matplotlib`` for visualization

Once the required packages have been installed, you can simply run 

.. code-block:: python

    pip install git+https://github.com/depablogroup/LCPOM.git


Altenratively, you can run

.. code-block:: python

    git clone https://github.com/depablogroup/LCPOM.git
    cd LCPOM
    pip install .
